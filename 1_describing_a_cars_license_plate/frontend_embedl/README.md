Frontend React for the vehicle license plate analyzer, integrated with the FastAPI API in [backend_embedl](../backend_embedl/).

## <font color="red">Stack</font>

- **Vite 6** - dev server and build tool
- **React 19** + **TypeScript** - UI tipada
- **TailwindCSS v4** - utility styles
- **shadcn/ui** (new-york style) - ready components
- **TanStack Query v5** - fetch and polling automatically
- **sonner** - toast notifications
- **lucide-react** - icons

## <font color="red">Structure</font>

```
frontend_embedl/
|-- src/
|   |-- components/
|   |   |-- ui/                # shadcn components (Button, Card, Tabs, ...)
|   |   |-- Header.tsx

|   |   |-- MediaPreview.tsx   # Image/video preview

|   |   |-- JobProgress.tsx    # Polling status
|   |   |-- ResultCard.tsx     # Analysis result

```

## <font color="red">How to Run?</font>

### <font color="blue">`1.` Install dependencies</font>

```bash
cd 1_describing_a_cars_license_plate/frontend_embedl
npm install
```

### <font color="blue">`2.` Configure environment variables (optional)</font>

```bash
cp .env.example .env
# By default, uses Vite proxy to http://localhost:8000
```

### <font color="blue">`3.` Start the backend (in another terminal)</font>

```bash
cd ../backend_embedl
./run.sh
```

### <font color="blue">`4.` Start the frontend dev server</font>

```bash
npm run dev
```

Access: http://localhost:5173

## <font color="red">Usage Flow</font>

1. Choose **Image** or **Video** in the tabs.
2. **Drag** the file or **click** to select.
3. See the **preview** of the file.
4. Click on **Analyze Plate**.
5. Follow the progress (polling automatically every 2 seconds).
6. See the descriptive result generated by the VLM.
7. Click on **New analysis** to restart.

## <font color="red">Scripts</font>

| Command | Description |
|---------|-----------|
| `npm run dev` | Start the dev server at http://localhost:5173 |
| `npm run build` | Build the production version in `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Check for TypeScript errors |

## <font color="red">Integration with the Backend</font>

- Proxy configured in [vite.config.ts](vite.config.ts):
  - `/api/*` -> `http://localhost:8000/api/*`
  - `/health` -> `http://localhost:8000/health`
- Variable `VITE_API_URL` in `.env` allows pointing to another URL.
- CORS is already configured in the backend for `localhost:5173`.

## <font color="red">Endpoints Consumed</font>

| Method | Endpoint | Action |
|--------|----------|------|
| `POST` | `/api/v1/jobs` | Upload the media file, returns `job_id` |
| `GET` | `/api/v1/jobs/{job_id}` | Polling the job status |
| `DELETE` | `/api/v1/jobs/{job_id}` | Clear the job (optional) |
| `GET` | `/health` | Server and model health status |
